# Judging System Specification

## Overview
DOGFOOD 2026 incorporates a multi-criteria scoring system for transparent hackathon project evaluation.

## Scoring Methodology
- **Multi-Criteria Evaluation:** Projects are evaluated across customizable criteria (e.g., Innovation, Technical Execution, Usability, Impact).
- **Weighted Scoring:** Each criterion contributes a weighted percentage to the overall project score.
- **Normalized Aggregation:** Scores across multiple judges are averaged and normalized to ensure fairness.

## Judge Workflow Lifecycle
1. **Assignment:** Submissions are allocated to assigned judges.
2. **Review:** Judges review project documentation, repository code, and demo links.
3. **Scoring:** Judges assign numeric scores and provide qualitative feedback per criterion.
4. **Finalization:** Scores are aggregated into leaderboard rankings once the evaluation period closes.
